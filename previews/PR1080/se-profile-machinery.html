SE and profile machinery ​

Lower-level standard-error and profiling building blocks: conditional latent-score SDs, a bootstrap driver over implied-covariance entries, a generic profile-curve wrapper, and a thin standard_errors convenience reader.

latent_score_sd: conditional score uncertainty ​

latent_score_sd(fit, Y) returns sqrt(diag(Cov(z | y, θ̂))) for the fitted latent factor scores z, conditional on the point estimate θ̂. The calculation holds θ̂ fixed, so its SDs exclude uncertainty in the fixed effects, loadings, and dispersion. TMB's default sdreport() for random effects also propagates uncertainty in the estimated fixed parameters. A conditional TMB comparison requires ignore.parm.uncertainty = TRUE, matching the conditional Laplace curvature described by Kristensen, Nielsen, Berg, Skaug & Bell (2016, J Stat Soft 70(5), §2.3).

The Laplace approximation treats the random-effect block as Gaussian at the mode. Its precision is the Hessian of the joint negative log-likelihood with respect to the random effects, evaluated at (ẑ, θ̂) (equivalently, the negative Hessian of the joint log-likelihood).

Two regimes:

  • GllvmFit (Gaussian) uses the exact closed form M = I_K + Λ'Ψ⁻¹Λ.

  • Binomial, Poisson, Negative Binomial, Gamma, and Beta use a Laplace approximation with the same per-site curvature assembled for the marginal likelihood's log-determinant term.

AGHQ-integrated fits use a different conditional covariance object, so this function raises ArgumentError when aghq > 0. Ordinal and other unsupported families raise MethodError when you call latent_score_sd.

This function was renamed from getREsd. R's getREsd(fit, block=) reads auxiliary TMB random-effect blocks (diag_unit, phylo, re_int, ...). GLLVModels.jl's latent_score_sd returns latent factor-score SDs. The old Julia name still resolves through a deprecated forwarding call.

bootstrap_Sigma: thin driver for one tier ​

bootstrap_Sigma loops the upper triangle of sigma_y_site(fit) and calls the existing bootstrap_ci_derived per entry; it adds no new bootstrap machinery. R's bootstrap_Sigma() bootstraps Sigma, correlation, communality, ICC, and cross-correlation across separate unit/unit_obs/phy tiers in one call; this driver covers only the Sigma entries at GLLVModels.jl's single site-level tier. level is validated (only :unit accepted) rather than silently accepted-and-ignored. The driver makes O(p²) bootstrap runs. This is practical for a small number of responses and expensive for many responses.

bootstrap_Sigma_r: the pinned-R bootstrap behaviour ​

bootstrap_Sigma_r follows R's bootstrap_Sigma() (gllvmTMB commit 9539352f6) more closely than the legacy bootstrap_Sigma above. It is a different estimand and a separate function; the legacy driver is unchanged and no decision has been made about replacing it. One batch of n_boot datasets is simulated from the fit, each is refit once, and every requested summary (Sigma, R, communality, ICC) is read from that one refit. Bounds are type-7 percentiles of the finite draws. The result is a BootstrapSigmaR.

Supported fit classes:

  • GllvmFit with no W tier, no pins, no phylogenetic block and no retained Gaussian record: tier :B only (Sigma_B, R_B, communality_B).

  • TwoLevelFit (pass individual): tiers :B and :W, plus ICC_site.

  • PrecisionMultivariateFit: tier :phy only (Sigma_phy, R_phy, communality_phy); the tier excludes the residual variance, as in R.

  • JointPhyloGroupedGaussianFit: tier :phy only, refused unless the original fit converged and its phylogenetic, ordinary and residual covariance components are identified (see below).

Everything else (other fit classes, K_W > 0 on a GllvmFit, a GllvmFit with a phylogenetic block, n_cores > 1) throws an ArgumentError. cross_corr is always skipped. A replicate whose refit throws or does not converge is counted in n_failed and left out of the percentiles. Defaults mirror R: n_boot = 999, conf = 0.95, progress = true; these defaults still need maintainer agreement.

A runnable walk-through (call, fields, bounds, warnings, refusals) is on the worked example page.

Caveats:

  • No output has been compared with R. The behaviour target is R's source, not an R run.

  • For a GllvmFit with has_diag = true and K_W == 0, tier B is the identified total sigma_y_site(fit), which includes the residual variance. That this equals R's unit tier rests on a Julia comment in extractors.jl, and is unverified against R.

  • For has_diag = false, communality_B is exactly 1 with a zero-width interval.

  • The capability row stays unbound: no row, score or tolerance changes.

The :phy tier for JointPhyloGroupedGaussianFit ​

Each replicate redraws the phylogenetic effect and, for every ordinary grouping term, one independent draw per group through the stored incidence matrix; loadings, fixed effects and variances are held at the fit. The phylogenetic part of the response is the only tier reported: Sigma_phy = LL' + diag(unique) contains neither the residual variance nor any ordinary-term variance. B and W are dropped with an @info: R would report B/W tiers for a comparable multi-tier fit, but how this class's ordinary terms map to R's B/W has not been verified, so Julia does not bootstrap them.

Deviations from R, all reported on the result (result.diagnostics):

  • A replicate counts as failed (in n_failed, excluded from the percentiles) when the refit throws, does not converge, or is not component-identified. R's rule is convergence only, so failure rates are not comparable with R's.

  • A converged replicate with a non-positive-definite Hessian is kept, as in R. The number of such replicates is reported, and a warning is issued when the original fit's Hessian is not positive definite. In the pre-run these replicates were 0% to 71% of the converged ones (33.7% and 71.4% in the two explicit-unique fixtures), and they often have a variance on its boundary, so percentile ends can be truncated there.

Evidence is structural plus a Julia descriptive pre-run only: six fixtures, one seed each, 200 replicates, in which 0% to 2.5% of replicates failed. With 200 replicates a count of 5 does not exclude a true failure rate above 5%. The fixture refits used g_tol between 1e-5 and 2e-4 and at most 200 iterations. No output has been compared with R; there is no R parity claim. Several configurations are untested in a real refit: more than one ordinary term, rank above 1, :unit_obs and :cluster2 terms, covariates beyond trait intercepts, larger and unbalanced trees.

standard_errors: an eager wrapper ​

standard_errors(fit, Y) is a thin wrapper around confint(fit; y=Y, ...), returning only term/estimate/se/pd_hessian. R's standard_errors() is a deferred-computation feature: gllvmTMB(..., control = gllvmTMBcontrol(se = FALSE)) skips TMB's sdreport() at fit time, and standard_errors(fit) computes it later. GllvmFit has no se = FALSE control, and its Hessian can be computed on demand. Here, standard_errors is a convenience reader rather than a lazy cache.

Profile curves ​

tmbprofile_wrapper re-walks GLLVModels.jl's existing bracket-then-bisect profile search, but records every evaluated (θᵢ, nll) pair instead of discarding them, giving the full profile trace R's tmbprofile_wrapper() (backed by TMB::tmbprofile()) returns. profile_curve_targets batches this over several named/indexed parameters into a Dict.

profile_phylo_signal(fit, t) profiles the raw packed parameter sigma_phy[t], the per-trait phylogenetic-unique SD scale. The profile_ci_phylo_signal function (see Derived confidence intervals) profiles the composite ratio phylo_signal(fit)[t]. These are separate estimands profiled by different engines.

Renamed: profile_targets → profile_curve_targets ​

R's profile_targets() is a readiness registry. It reports which parameters could be profiled without running TMB::tmbprofile(), which uses a live checkpoint for faster execution. GLLVModels.jl has no comparable checkpoint step. Its profile_curve_targets function runs each target's curve directly. The old name, profile_targets, remains as a deprecated forwarding call and is documented here for migration.

GLLVModels.latent_score_sd Function
julia
latent_score_sd(fit::GllvmFit, y; X=nothing, rotate=true) -> Matrix{Float64}

Posterior (conditional-on-θ̂) standard deviations of the latent factor scores for a Gaussian GLLVM fit. Returns an n_sites × K matrix. The Gaussian conditional covariance M = I_K + Λ' Ψ⁻¹ Λ (Ψ = Σ_y − ΛΛ') does not depend on the site, so every row is identical.

rotate (default true) MATCHES getLV's own default: the SDs are reported in the same canonical SVD-rotated basis (sqrt.(diag(R' M⁻¹ R)), R =rotation(fit)) that getLV(fit, y; rotate=true) (the default) uses for its conditional MEAN. Pass rotate=false for the unrotated sqrt.(diag(M⁻¹)), paired with getLV(fit, y; rotate=false). Mixing rotate=true scores from one call with rotate=false SDs from the other (or vice versa) puts the point estimate and its SD in different bases — always request the same rotate value from both.

y (and X, if the fit used fixed effects) is required to reconstruct Σ_y's scale in the same way getLV does; only its size is used here (the covariance does not depend on the response values), but the argument is kept for interface parity with getLV and to guard against a site-count mismatch with a caller's other post-fit calls.

These SDs are EXACT (not Laplace-approximate) given θ̂ — see the module docstring above for the derivation and the accompanying finite/closed-form test.

STRUCTURAL SCOPE: refuses (with an honest ArgumentError) for fits this closed-form identity does not cover — a phylogenetic block (K_phy > 0 or has_phy_unique; the phylo effect is shared across sites, breaking the per-site-independent conditioning this formula assumes), a K_W (within/ unit_obs) tier, or a masked/offset/AGHQ Gaussian-record fit (Σ_y_sitefrom sigma_y_site does not reconstruct the record objective's actual per-cell covariance for those fits).

GLLVModels.bootstrap_Sigma Function
julia
bootstrap_Sigma(fit::GllvmFit; level=:unit, n_boot=500, conf=0.95,
                seed=0, y=nothing, n_sites=nothing, X=nothing,
                Σ_phy=nothing, verbose=false)
    -> NamedTuple

Parametric bootstrap percentile CIs for every entry of sigma_y_site(fit) (the fitted site-level trait covariance Σ_y = Λ Λ' + diag(d_total)), via bootstrap_ci_derived (src/confint_derived.jl) applied entrywise.

level = :unit is the only value accepted: GLLVModels.jl computes one site-level Σ_y per fit (sigma_y_site), not R's separate unit / unit_obs / phy tiers, so level is kept for interface parity with R's bootstrap_Sigma(level = ...) and validated rather than silently ignored.

Returns a NamedTuple table over the upper-triangle entries (i ≤ j, 1-based) of Σ_y:

  • i::Vector{Int}, j::Vector{Int}

  • estimate::Vector{Float64} — Σ_y[i,j] at θ̂

  • lower::Vector{Float64}, upper::Vector{Float64} — percentile CI at conf

  • n_converged::Vector{Int}, n_valid::Vector{Int}

y, n_sites, X, Σ_phy are forwarded to bootstrap_ci_derived exactly as documented there (pass the same values used for fit_gaussian_gllvm).

Cost: p(p+1)/2 × n_boot refits (one full bootstrap_ci_derived bootstrap run per matrix entry) — quadratic in p. Use the full table for small trait matrices. For larger p, lower n_boot or call bootstrap_ci_derived directly for only the entries you need.

R's bootstrap_Sigma() also bootstraps R (correlation), communality, ICC, and cross_corr in the SAME call, over multiple covariance tiers. This driver covers only the Sigma entries at the single :unit tier GLLVModels.jl has. The other summaries are already independently reachable via bootstrap_ci_derived(fit, fb -> communality(fb)[t]; ...) / bootstrap_ci_derived(fit, fb -> correlation(fb)[i,j]; ...); a unified multi-summary table matching R's return shape is not yet available.

GLLVModels.bootstrap_Sigma_r Function
julia
bootstrap_Sigma_r(fit::Union{GllvmFit,TwoLevelFit,PrecisionMultivariateFit,
    JointPhyloGroupedGaussianFit}; n_boot=999,
    level=(:unit,:unit_obs,:phy,:B,:W), what=(:Sigma,:R,:communality,:ICC,:cross_corr),
    conf=0.95, seed=nothing, n_cores=1, progress=true, keep_draws=false,
    link_residual=:auto, y=nothing, n_sites=nothing, X=nothing, Σ_phy=nothing,
    individual=nothing, center=true) -> BootstrapSigmaR

Parametric percentile bootstrap of covariance summaries, following the pinned R bootstrap_Sigma (gllvmTMB 9539352f6). GllvmFit (no W tier, no pins, no phylo block, no retained record): tier :B only; Sigma, R, communality; ICC is dropped and cross_corr is always skipped (R needs a multinomial trait). TwoLevelFit (pass individual): tiers :B, :W and ICC_site. PrecisionMultivariateFit and JointPhyloGroupedGaussianFit: tier :phy only (see below). Everything else throws ArgumentError. n_cores > 1 is refused. See the ledger Spec for the full contract; the legacy bootstrap_Sigma is a different estimand and is unchanged.

What tier :B means for a GllvmFit (it changes with has_diag)

  • has_diag = false (rr-only): Sigma_B = ΛΛ' only. There is no diagonal and no σ_eps². Sigma_B is rank-deficient (rank K), and for K = 1 R_B is degenerate (all off-diagonals are ±1). communality_B is exactly 1 with a zero-width interval (shared ΛΛ' over total ΛΛ'); it carries no information, and an @info says so.

  • has_diag = true and K_W == 0: Sigma_B is the identified total sigma_y_site(fit) = ΛΛ' + diag(σ²_B + σ²_W + σ_eps²), so it DOES include σ_eps² and σ²_W; communality_B = diag(ΛΛ') ./ diag(Sigma_B) uses that total as denominator. UNVERIFIED against R output: that this equals R's unit tier for such a model rests on a Julia comment (extractors.jl:270-276) and was never compared with an R run.

Sigma_B, R_B and communality_B are therefore different estimands in the two cases; do not compare them across has_diag settings.

PrecisionMultivariateFit (tier :phy only)

Maps to R's phylogenetic tier: mode = :barelowrank is phylo_latent alone, :explicitunique is phylo_latent + phylo_unique. Sigma_phy = ΛΛ' + diag(unique) with NO residual variance (R's Gaussian Sigma_phy), R_phy its correlation, communality_phy = diag(ΛΛ') ./ diag(Sigma_phy) (R: link residual "none"). B, W and ICC_site do not exist for this class (dropped with an @info at the default level; level = :B alone throws); cross_corr is never produced; y, n_sites, X, individual and Σ_phy are refused (the fit stores its tree, response shape and mean design). mode = :barelowrank gives communality_phy exactly 1 with a zero-width interval (flagged by an @info).

Each replicate redraws every phylogenetic effect from its fitted law with the loadings held fixed (R's unconditional simulate: one tree-correlated draw per latent axis, and, with a unique component, one per trait), adds the fixed effects mean_design * beta and residual noise, and is refit once from default starts (no warm start, no relative f_tol). This is a parametric bootstrap conditional on the tree, species_id, mean design and fitted parameters; it is not a bootstrap of tips. Caveats:

  • The RNG stream cannot match R's: parity is distributional only.

  • Sigma_phy is on the scale of the supplied tree (sigma2_phy is fixed at 1); compare across trees through R_phy or communality_phy only.

  • DEVIATION in the failure rule: R fails a replicate on opt$convergence != 0; here a replicate fails when the refit throws or !converged, and converged also needs a fresh finite-difference gradient norm below g_tol. Failure rates are therefore not comparable with R's. The Hessian is checked by neither implementation.

  • The simulator uses a dense Cholesky of the tree precision (O(n_aug^3)): fixtures and modest trees only.

  • Small tip counts give biased, boundary-truncated percentile intervals for variance components (R shares this). Coverage has not been assessed.

  • EVIDENCE LEVEL: structural. The contract was read from the pinned R source and is pinned by tests and mutation checks; the simulator law is checked against the model covariance and the fitter's own likelihood. NO numerical comparison with an R bootstrap_Sigma run exists, so "matches R output" is not claimed. (R's own test-suite has no phy-tier bootstrap test.) center is ignored.

JointPhyloGroupedGaussianFit (tier :phy only; refused unless the ORIGINAL fit is identified and converged)

Sigma_phy = ΛΛ' + diag(unique) (fit.phylo_covariance): it contains NEITHER the residual variance NOR any ordinary grouping-term variance; those are separate sources and are never added to the phy tier. R_phy and communality_phy = diag(ΛΛ') ./ diag(Sigma_phy) follow. Each replicate redraws every phylogenetic effect as for PrecisionMultivariateFit AND, for each ordinary term, one independent N(0, diag(ordinary_covariances[k])) draw per group, added through the stored incidence matrix; loadings, fixed effects and variances are held at the fit. Each replicate is refit once from default starts (no warm start, no relative f_tol; the fitter's defaults g_tol = 1e-5, iterations = 200), with the same tree, rank, phylo mode, terms, species_id and mean design. Group labels are recovered from the stored incidences and passed under each TERM's keyword (unit, unit_obs, cluster, cluster2), so only the partitions (not the original label values) are kept. B and W are dropped with an @info (default level; level = :B alone throws) and ICC is dropped.

DEVIATIONS from the pinned R, all counted and reported:

  • Failure rule. A replicate FAILS (is in n_failed, NaN-shaped, excluded from the percentiles) when the refit throws, does not converge (converged also needs a finite-difference gradient norm below g_tol, unlike R's nlminb convergence code), OR its covariance components are not identified (_joint_phylo_grouped_component_identification(refit).reason !== :identified). R's rule is convergence only and has no identification check. The breakdown is in result.diagnostics (n_thrown, n_not_converged, n_non_identified; they sum to n_failed). Failure rates are therefore not comparable with R's.

  • B/W omitted. R would report B/W tiers for a comparable multi-tier fit. How this class's ordinary terms map to R's B/W is unverified, so they are not bootstrapped.

  • Silenced fitter warning. The fitter's per-replicate "not separately identifiable" @warn is silenced in the loop and counted in diagnostics.n_non_identified. Exceptions are not silenced.

Curvature. A converged replicate with a non-positive-definite Hessian is KEPT (as in R, which checks only convergence, and as the percentile method needs only point estimates), and counted: diagnostics.n_converged (converged replicates, identified or not) and diagnostics.n_hessian_not_pd (of those), reported in an @info. Such replicates often have a variance on its boundary (a unique or ordinary variance near 0), so percentile ends of quantities that depend on it can be truncated there. If the ORIGINAL fit's Hessian is not positive definite (diagnostics.original_hessian_pd == false) a @warn says so; the run proceeds. In a pre-run on fixtures the non-PD fraction among converged replicates was 0% to 71%: 33.7% and 71.4% in the two explicit-unique cases.

EVIDENCE LEVEL: structural plus Julia-descriptive. The contract is read from the pinned R source for the shared parts and pinned by tests and mutation checks. The only other evidence is a diagnostic pre-run (six fixtures, one seed each, n_boot = 200, g_tol 1e-5 to 2e-4, up to 200 iterations) in which 0% to 2.5% of replicates failed (thrown, non-converged or non-identified); with n_boot = 200 a count of 5 does not exclude a true failure rate above 5%. Not tested: more than one ordinary term in a real refit, rank above 1 in a real refit, :unit_obs and :cluster2 in a real refit, covariates beyond trait intercepts, larger trees, unbalanced trees. NO numerical comparison with an R run exists and NO R parity is claimed; link_residual and center are ignored.

Other behaviour worth knowing

  • X is the p x n_sites x q design array used at fit time (a 2-d matrix is refused) and must agree with n_siteswhen both are given. For a fit fromfit_gllvm(Y; family = Normal(), K)(trait intercepts) noXis needed, butn_sites(ory) still is.ymust be p x n; onlysize(y, 2)is read, its values are ignored.n_sites must be at least 2.

  • link_residual is validated and stored on the result but has no effect for these Gaussian fits. boot_median is accepted by the R list but is always an empty NamedTuple here (not computed). For a TwoLevelFit, y, n_sites, X and Σ_phy are ignored; for a GllvmFit, individual and center are ignored.

  • A warning always fires when ANY replicate is lost (refit failed, or the summaries could not be extracted), whatever what is requested; it names the count out of n_boot. n_failed itself counts failed refits only: an extraction error on a converged refit blanks that replicate but is not in n_failed (see below).

  • progress = true emits one @info per replicate (about 1000 at the default) and the default level always logs a "level(s) ... dropped" @info; pass progress = false and an explicit level for quiet output.

  • Correlation bounds (R_*) are clamped to [-1, 1] only when they overshoot by rounding (at most 1e-8); a larger excursion is left as is so a genuine error stays visible.

  • A replicate summary of the wrong shape becomes a NaN draw and is counted in the "lost" warning (not in n_failed), like an extraction error.

  • n_sites between 2 and p is accepted, but a fit with fewer sites than traits usually fails every refit: the result is then all-NaN, announced only by the "lost" warning.

  • For has_diag = true the built-in refit (not a user _refit) uses iterations = 2000, f_tol = 1e-12 (R's nlminb stops on a relative objective change); a deviation from the pinned R. It rescues the replicates that hit the stock 500-iteration cap and moves even already-converged replicates slightly (bounds by about 1e-5 in the fixtures measured).

  • Entries whose point estimate is itself non-finite (for example a zero-variance trait) are not counted in the attrition warning.

  • TwoLevelFit does not store center; the refit assumes center = true unless the keyword says otherwise. Simulated data are zero-mean.

  • boot_median is an empty NamedTuple, as in R: the pinned R fills boot_median only for multiple_r_* entries (R/bootstrap-sigma.R:717-720), which Gaussian fits never have.

  • Draws are filtered with isfinite; R's quantile(na.rm = TRUE) drops only NA/NaN, so a ±Inf draw is dropped here but would be kept by R (not expected to arise).

  • A refit that throws or returns a non-converged fit is a failed replicate. An error while extracting summaries from a converged refit blanks every entry of that replicate to NaN and is NOT counted in n_failed (R skips per level; here one or two tiers make the difference small). InterruptException is never swallowed.

  • n_boot = 999 and progress = true (one @info per replicate) mirror R and need maintainer agreement as Julia defaults.

GLLVModels.standard_errors Function
julia
standard_errors(fit::GllvmFit, y; X=nothing, Σ_phy=nothing, level=0.95)
    -> NamedTuple

Julia analogue of R gllvmTMB's standard_errors(). R's version lazily defers TMB's sdreport() to a later call when a fit was made with control = gllvmTMBcontrol(se = FALSE) — a "fit fast now, get SEs later" door. GLLVModels.jl's GllvmFit has no such deferred-SE control: the observed- information Hessian is always available on demand via confint.

standard_errors is therefore a thin, always-eager wrapper around confint(fit, y; level=level, X=X, Σ_phy=Σ_phy), returning only the term/estimate/se/pd_hessian fields (the CI-bound-free subset R's downstream consumers — summary(), getREsd(), confint(method = "wald") — actually read off sd_report). Since GLLVModels.jl never skips the computation, fit is returned unchanged (it is immutable) and the NamedTuple result stands in for R's "populate sd_report and return the fit" side effect.

GLLVModels.tmbprofile_wrapper Function

tmbprofile_wrapper(fit::GllvmFit, param_index::Integer; level=0.95,
                   grid_extent=5, max_expand=20, max_bisect=30,
                   profile_iterations=200, profile_g_tol=1e-4,

Bare profile-CURVE variant of profile_ci — the Julia analogue of R's tmbprofile_wrapper()/TMB::tmbprofile() pair. profile_ci already reproduces the REDUCED bound R's function returns; this exposes the underlying (θ_i value, nll) TRACE that bound is reduced from (see the comment block above this method for the derivation).

Returns a NamedTuple:

  • nll::Vector{Float64} — negative log-likelihood at each constrained refit, in the same order as theta

  • estimate::Float64 — θ̂_i (the packed value at param_index, on the WORKING scale — no exp back-transform, unlike profile_ci's lower/ upper, since a raw NLL curve is inherently on the working scale)

  • lower, upper, method — identical to profile_ci(fit, param_index; kwargs...), i.e. already back-transformed for :log_sd terms

profile_curve_targets(fit::GllvmFit, targets=nothing; kwargs...)
    -> Dict{String, NamedTuple}

Batch curve wrapper: calls tmbprofile_wrapper for every entry of targets (a vector of packed-parameter names or integer indices; default nothing profiles EVERY term in confint(fit).term order), returning a Dict keyed by term name.

R's profile_targets() is a READINESS REGISTRY (which parameters/targets a fit COULD be profiled on, without running anything, because TMB::tmbprofile() needs the fit's live tmb_obj checkpoint machinery to run cheaply and reversibly). GLLVModels.jl's profile_ci has no comparable checkpoint/restore step — running it IS the cheap operation — so this function runs every target's curve directly rather than reporting a separate readiness flag; a fit for which a given parm cannot be resolved (see profile_ci's parm-name resolution) raises the same ArgumentError that resolution already raises elsewhere in this file, which is the honest failure mode.

kwargs (in particular y, and X/Σ_phy if the fit used them) are forwarded verbatim to every tmbprofile_wrapper call.

GLLVModels.profile_phylo_signal Function
julia
profile_phylo_signal(fit::GllvmFit, t::Integer; kwargs...) -> NamedTuple

Bare profile-CURVE variant scoped to the per-trait phylogenetic-unique scale sigma_phy[t] (a raw packed parameter on an identity, signed link — no exp back-transform; present iff the fit used has_phy_unique = true).

σ_phy is a signed parameter (#136), so this curve can extend below zero. When K_phy = 0, the sign of each group of rows that Σ_phy links can flip on its own (for a tree-derived Σ_phy, each daughter clade of the root); when K_phy ≥ 1, it is not identified separately from Λ_phy and a per-entry interval is not interpretable. It is not gllvmTMB's phylo_unique scale; see the gllvmTMB parity page.

Honest scope note: this is NOT the composite phylogenetic-SIGNAL summary phylo_signal(fit)[t] (an H²-like ratio of variance components) that profile_ci_phylo_signal (src/confint_derived.jl) already profiles via its own constrained-refit-WITH-PENALTY machinery on that nonlinear derived quantity. Building a curve variant for THAT quantity needs the identical penalty-profile plumbing confint_derived.jl already owns; duplicating it here would create two divergent implementations of the same profile, so this function is deliberately scoped to the packed sigma_phy[t] term — the raw SCALE parameter, not the derived SIGNAL ratio.
