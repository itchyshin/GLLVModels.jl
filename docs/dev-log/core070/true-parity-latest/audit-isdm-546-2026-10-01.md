# Audit: which of the 20 isdm rows #546's receipts genuinely test (2026-10-01)

Scope. The 20 isdm rows of `case-map-isdm.json` (itchyshin/GLLVModels.jl#587) each record an R admission predicate at P1 (`9539352f6`) that returns TRUE. None had a number. Itchyshin/GLLVModels.jl#546 (merged) holds R-at-P1 vs Julia comparisons for four fitted integrated-SDM cases through R's public door. This audit asks, row by row, whether one of those comparisons tests what the row's predicate is about. Test used: a fit-level logLik / estimate comparison pays a row only if the fitted case exercises the row's path, so that agreement would fail if Julia's path differed from R's.

The four fitted cases (all balanced, no NA responses, `offset(log_support)` in every formula):

| case | sources and laws | observation formulas | latent |
| --- | --- | --- | --- |
| predict | gbif Poisson, survey Bernoulli-cloglog | none (`trait:src_gbif` in the ecological part) | d = 1 |
| ms3 | gbif Poisson, literature Poisson, survey Bernoulli-cloglog | none | d = 1 |
| srcform_pois | gbif, inat, survey all Poisson | gbif `~access`, survey `~observer + method` | none |
| srcform_mixed | gbif Poisson, inat Poisson, survey Bernoulli-cloglog | gbif `~access`, survey `~observer + method` | none |

Each fit has four receipt cases (test/parity/isdm_cases.jl, tolerances read from the assertion lines): Julia marginal at R's optimum vs R logLik (1e-6, line 195); R objective at Julia's optimum vs Julia logLik (1e-6, line 200); fresh-fit b_fix vs R, max abs (1e-4, line 225); fresh-fit eta vs R, max abs (1e-4, line 217). Receipts: `receipts/julia-twins/isdm/{predict,ms3,srcform_pois,srcform_mixed}.json`.

## What the binding does and does not say

It says Julia reproduces R's logLik at R's parameters, R's objective at Julia's optimum, and R's estimates and linear predictor, on the four fits, so the designs, offsets and mixed-law handling those fits use agree. It does not say that R's admission predicates and Julia's hand-translated analogues (#546's `P1-ISDM-ADMISSION-20`) agree; that is a boolean pairing, no number, and was not used. The 5 bound rows keep their R predicate receipts un-cited under `non_binding_receipts` and `r_predicate_case_ids`.

Convergence caveat (from #546): R's nlminb stops at max abs gradient 3.9e-4 to 9.0e-4 on the K = 0 fits, so the b_fix case is a loose absolute bound (observed 2.6e-6 to 2.1e-5 against 1e-4); the logLik cases carry the strict tolerance.

`tools/core070_isdm_p1_receipts.py` now keeps any row whose evidence.receipt points under receipts/julia-twins/ or receipts/fixture-twins/ (with its case ids, tier and measured_against), re-derives everything else, and recomputes the counts block; `--check` passes and still fails on drift.
