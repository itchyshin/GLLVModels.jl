## 1. What PR #518 contains

Reading `git log --oneline origin/main..HEAD`, this branch adds
automatic latent-dimension (`K`) selection to `fit_gllvm`:

- `select_lv(Y; family, Kmax, criterion = :bic_sites, ...)`
  (`src/model_selection.jl`) sweeps `K = 1:Kmax`, fits each, guards
  against non-converged / non-improving / runaway fits (with a
  warm-start retry from the smaller-`K` solution where the family
  allows it), and reports the criterion table plus every attempt with a
  status/reason. `criterion = :bic_sites` (BIC with `log(n_sites)`
  instead of `log(p*n)` cells) is the maintainer-signed-off default
  (D-293, commit `9ced6500e`).
- `fit_gllvm(Y; family, Kmax, ...)` with `K` omitted now dispatches
  through `select_lv` itself (`Kmax` default `min(5, p - 1)`), returning
  the chosen fit with a one-line message (commit `cbd61b1b3`).
- `fit_binomial_gllvm`'s `loading_ridge` keyword (already documented in
  its own docstring) is used automatically by `select_lv`/`fit_gllvm`'s
  sweep for single-trial binomial data via a `binary_ridge` default
  (commit `0b3f5d117`, "loading ridge for binary data; penalised
  monotone check").
- `require_converged`-equivalent guard behaviour (commit `e77ca2ec6`)
  and D-43 panel review fixes (commit `a7678b3a2`) harden the sweep.
