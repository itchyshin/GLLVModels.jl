# After Task: False `converged` on three fitters

## Goal

Stop `fit_branch_re`, `em_fit_phylo`, and `fit_zinb_gllvm_cov(iterations = 0)`
from reporting `converged = true` when the fit is not an interior optimum
(refs #754, #753, #781). Reproduce each defect on current main first.

## Implemented

On `origin/main` `e6cfcd4ee` the three issue repros still fire. The branch
adds an x-spread test and a stated variance-boundary flag to `fit_branch_re`,
records the `σ_eps² = eps()` M-step clamp on `EMPhyloFit`, and makes the
ZINB+X `iterations <= 0` path a documented start-only check with
`converged = false` and a finite `θ_init` guard. No new absolute gradient
or objective tolerance. `converged` is the optimiser/increment result plus
these checks; nothing hard-codes `true`.

## Mathematical Contract

Unchanged likelihoods. Branch-RE remains the single-variance BM
`y ~ N(μ·1, σ² V + σ²_eps I)` with μ profiled by GLS. EM remains the
Gaussian phylo factor model of `em_fit_phylo` (Hadfield & Nakagawa
augmented-state / closed-form Gaussian marginal). ZINB+X remains the
two-part Laplace marginal with shared scalar `r`. Only the convergence
and input-check contracts change.

## What Did Not Go Smoothly

no `graft/` tree on disk), so location came from the issue spans and
direct reads. Julia 1.10.12 had to be installed via juliaup on the
snapshot. The #753 issue text still quotes `dof = 1`; current main
already reports `dof = 11` (#745). The noise-only branch-RE fit now
walks further toward zero (`σ²` 6e-10 → 1e-14, 55 → 121 iterations)
because x-spread keeps the simplex moving; the boundary flag is the
user-visible signal.

## Team Learning

False-`converged` defects in this cluster share a shape — a stop rule
that ignores a clamp, a feasibility check, or a zero-iteration path —
and should be hunted as a family, not one fitter at a time.

## Known Limitations

parameters and a finite log-likelihood; the change is that `converged`
is false and a boundary field is true. Constant / non-finite `y` now
error instead of returning a number.
