# After Task: README Y and Binomial λ_init (#1007, #1008)

## Goal

Make every README Julia example run in a fresh session, and accept
`λ_init` on the Binomial Laplace path (and sibling family routes that
already take `Λ_init`) without changing defaults.

## Implemented

The README Poisson optimizer block now defines the same responses-by-sites
count matrix used in the matched-start block. The confidence-interval
block is self-contained. `λ_init` is an alias of `Λ_init` on non-Gaussian
`fit_gllvm` routes and on the binomial, Poisson, NB2, Beta, and Gamma
Laplace fitters. Passing both with different values throws. Omitting both
keeps the existing warm start. Two-part and zero-inflated routes still
have no loading-start keyword.

## Mathematical Contract

Unchanged likelihood, packing, and warm start. Only the start-keyword
name is accepted.
