- **R scaffold `gllvm_julia()`: NB1 with a row effect stops before any fit (refs #1271).** `gllvm_julia(family = "negative.binomial1", row.eff = "fixed"` or `"random")` mapped NB1 to the NB2 marker and dispatched to the row-effect fitters before the NB1 branch, so the request silently fitted NB2 and then died in a Julia `FieldError` while reading the dispersion. After the family is looked up, and before the link check or any fit, the call now stops with an R error that names the family and the option and says what to use: `row.eff = "none"` with NB1, or `family = "negative.binomial"` (NB2) to keep the row effect. NB1 without a row effect and every other family are unchanged. Draft PR #1261 refuses `NB1()` with a row effect on the Julia side; this scaffold path never passes that marker, so the R stop is needed in addition. `test/auto/test_gllvm_julia_nb1_roweff_guard_1271.jl` pins the message and the pre-fit placement.
