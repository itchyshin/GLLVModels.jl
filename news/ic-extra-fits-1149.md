- **`loglikelihood`, `dof`, `aic`, `bic(fit, n)`, `bic(fit, Y; mask)` and `nobs(fit, Y; mask)` now work for `OrderedBetaFit`, `QuadraticFit` and `MixedFamilyFit` (refs #1149).** These three fits stored a `loglik` but every generic raised `MethodError`. Same conventions as the other fits: `aic = 2k - 2ll`, `nobs` is the `p*n` observed-cell count, `bic(fit, Y)` uses it. The parameter count `k` is the one already coded for `OrderedBetaFit` and `QuadraticFit`; for `MixedFamilyFit` it is `beta + reduced Lambda + n_disp` (one dispersion per dispersion-carrying trait). Not added here: `residuals` for the types in the issue, and `coef`, `coeftable`, `stderror`, `deviance`, `simulate`.
