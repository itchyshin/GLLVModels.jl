### 2. Every branch return is `-Inf` or a certified stationary point: almost

3000 branch returns (1.10 + 1.13). 2992 certified stationary under my objective, 4
`-Inf`, 4 finite and declared `ok = true` but not stationary under my objective. The 4
non-stationary ones are all the same pre-existing clamp artefact (S3), not this PR's
defect class: a Beta trait with `y` at the 1e-6 boundary and `mu` below the kernel's
1e-6 `_clamp_mu`, where the kernel's score field (score at clamped mu, times
`mu_eta` at unclamped eta) is not the gradient of the clamped merit function it line
searches on. The kernel's own `Lambda's - z` is < 1e-8 at those points; the true
unclamped gradient is not zero either. Same construction in every kernel in the repo
(`_clamp_mu` before scoring), so out of scope here; on main these same 4 sites were
garbage (e.g. PGBB 295: main z of order 1e3, value -7.4e13; branch -33.7).

The 4 `-Inf` returns are false negatives (S2): at each, a genuine interior mode exists
(Optim Newton on the kernel's OWN `_mixed_logpost` converges, `-H` PD), and the branch's
final z is within 2e-4 .. 1e-3 of it. Mechanism, measured: the spectral radius of the
undamped Fisher fixed-point map `I - A^{-1}(-H)` at the mode is 1.05, 1.04, 6.66 and
1.33 (> 1), so undamped Fisher scoring cannot contract there (a Gamma trait with shape
0.5 and `y/mu` of about 5 is enough: observed weight 2.6 vs Fisher 0.5). The PR's loop
takes any step with `norm(Delta) <= 1e-3 (1 + norm(z))` WITHOUT the line search, so
once near the mode it oscillates with growing amplitude, gets pulled back by a halving
when the step grows, and never satisfies both tolerances in 2000 iterations. Re-tracing
the same loop with the line search applied to every step converges in about 20
iterations on PBG 195. On main these 4 sites were finite-and-wrong, so this is
garbage -> loud, not a regression; but it is not "a diverging site", it is the kernel's
own shortcut.

### 4. Whole fits (`fit_mixed_gllvm`), 20 datasets, main vs branch, Julia 1.10

`probe_fits.jl`: same 5 mixes, p = 4..8, four designs each (n, K, loading scale) =
(30,1,0.7), (50,2,0.7), (40,2,1.2), (60,1,1.5); identical `Y`/`N` on both sides.
"Healthy on main" = main's outer fit reports converged AND every site at main's fitted
theta is certified stationary by my checker (15 of 20 qualify; the other 5 are main's
defect showing at fit level, or the outer optimiser hitting its 500-iteration cap
identically on both sides).

Healthy-on-main fits (15): 13 agree to |dLL| <= 3e-10, |dbeta| <= 1e-6 (dispersion
diffs of 1e9..1e13 on those are NB `r` running to its Poisson limit, not meaningful).
Two change materially:

- **NNbB design 3** (p=6, n=40, K=2): |dLL| = 1.42e-2, |dbeta|max = 6.9e-2 (beta[5]
  0.246 -> 0.178), |d(Lambda Lambda')|max = 0.19, NB `r` for trait 5 goes 6.39 -> 24.26.
  Branch's optimum is genuinely better: under the BRANCH likelihood LL(theta_main) =
  -262.6817, LL(theta_branch) = -262.6672. Cause: under MAIN's kernel, LL(theta_branch)
  = -10396 (site 18 diverges to z = (-97, -92), value -10140), i.e. main's likelihood
  surface is corrupted next to the true optimum, so main's L-BFGS stopped early with
  `converged = true`. A better optimum, and still a change. This is the largest
  healthy-fit change.
- **ALL6 design 2** (p=6, n=50, K=2): |dLL| = 2.2e-4, |dbeta|max = 2.9e-4. Direction:
  branch is WORSE. Main's optimum has Normal sigma = 2.3e-12 for trait 1 (a Heywood
  case; all 50 sites certified stationary there under main's kernel, nd_max 3e-10). Under
  the BRANCH kernel, LL(theta_main) = -Inf: every one of the 50 sites returns
  `ok = false`, with |Delta| about 1e-17 (converged by the step test) but |g| between
  0.03 and 2e7, because with W = 1/sigma^2 = 2e23 the absolute gradient `Lambda's - z`
  cannot be driven below 1e-6 in floating point. The branch fit therefore stops at
  sigma = 1.9e-5 with a slightly lower log-likelihood. This is S1 and it is the
  PR's own design choice, not the fixed defect.

Non-healthy-on-main fits show the fix's value at fit level: PBG design 4 main reports

## Should fix

- **S1 (recommend before merge). Absolute `grad_tol` walls off high-curvature sites with
  `-Inf`.** `maximum(abs, g) < grad_tol` on the unscaled `Lambda's - z` is unattainable
  when `A = Lambda'W Lambda + I` has eigenvalues of order 1e10 or more (Normal sigma
  below about 1e-5, i.e. a Heywood case, which the fitter's free `log sigma` can and does
  reach; ALL6 design 2 above). Main's step-only test converged correctly there. Make the
  gradient test scale-aware, e.g. the Newton decrement `abs(dot(g, Delta)) < grad_tol`
  (both quantities are already in hand), or `maximum(abs, g) < grad_tol * (1 +
  maximum(W) * opnorm(Lambda)^2)`. Re-run the ALL6-style Heywood case after the change.
- **S2. Small-step shortcut lets a non-contracting Fisher map oscillate to `-Inf`.**
  Where the Fisher fixed-point map has spectral radius > 1 at the mode (Gamma shape 0.5
  with `y/mu` far from 1; Beta phi 20 mixed with Poisson), steps under
  `1e-3 (1 + norm(z))` skip the line search and the iterate never settles; 4/3000
  random sites, genuine mode present in every case. Cheapest fix: once a full step has
  been rejected in this call, line-search every subsequent step (or drop the shortcut
  entirely; the `_mixed_logpost` evaluation is one pass over `p` traits). #507's
  observed-curvature fallback direction is the heavier alternative; the PR's claim that
  it is not needed here rests on "Fisher is a valid ascent direction", which is true but
  does not make the undamped map contracting.
- **S3 (note, not this PR).** Beta traits with `y` at the 1e-6 boundary and `mu` under
  `_clamp_mu`'s 1e-6: the kernel's score field is not the gradient of its own clamped
  merit function, so "certified stationary" is stationary for the score field only.
  Shared by every kernel that clamps `mu` before scoring; file under #503's tracking
  notes rather than fixing here.
- **S4. Wrong rationale in the body, CHANGELOG and the kernel comment.** "A Normal trait
  under IdentityLink has a sigma-only Fisher weight that does not track the residual,
  exactly the defect #509 found for Student-t." For Normal/identity the Fisher weight
  `1/sigma^2` IS the observed curvature (the log-likelihood is quadratic in eta), so
  Fisher scoring is exact Newton for that trait and the step-only test is safe for it.
  Student-t's Fisher/observed gap has no Normal analogue. The gradient check's real
  effect is S1. Rewrite the sentence in all three places (or drop the gradient check in
  favour of the scale-aware form in S1).
- **S5. Healthy-fit claim in the body is too strong.** "Floating-point-noise-level
  changes, not a different optimum" held on 13 of my 15 healthy datasets, not on NNbB
  design 3 (better optimum, |dLL| 1.4e-2, NB `r` x4) or ALL6 design 2 (`-Inf` at main's
  optimum, branch stops short). The CHANGELOG's "specific to those datasets, not a
  general bound" is the honest form; the body should say the same and name the Heywood
  case.
- **S6 (minor).** `abs(v_old - v_old_ref) < 1.0` pins a 1e13 garbage value across
  platforms; `!conv_old && isfinite(v_old) && abs(v_old) > 1e6` says the same thing
  robustly. Also the dead comment in `_stress_probe` ("cross-check: the site value
  GLLVModels reports agrees with an independent evaluation ...") describes an assertion
  that is not there.
