## Blocking-adjacent finding (small, mechanical)
`LOOP/checkpoint.md`'s new note says the §2 Hessian decision "was ACCEPTED
(option A) and applied 2026-09-15 (PR #347, merged `3091fe61`)." Commit
`3091fe61` is real and is PR #347's merge commit, but PR #347's actual diff
(`git show 3091fe61 --stat`) touches `src/confint_family.jl`,
`tools/core070_second_order/{cells,common}.jl`, and Delta-family test/doc
files only — it is "Delta shared-η Wald follow-up batch," unrelated to the
Binomial/cloglog or Tweedie-grouped Hessian selector. The decision document
itself only cites `3091fe61` as its **base commit** ("Base: `origin/main` @
`3091fe61` (post–PR #347 second-order Delta follow-up)") and says the actual
code (`_default_hessian(::Binomial, ::CLogLogLink) = :observed` in
`src/families/binomial.jl`; the Tweedie grouped default in
`src/families/grouped_dispersion.jl`) was "already on HEAD" at that point —
i.e., landed in some earlier, unidentified commit, not in #347. The new
status note in this PR conflates "decision's base commit" with "PR that
applied the fix," misattributing the engine change to #347.
