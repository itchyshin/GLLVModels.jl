**Verdict: MERGE**

## What it claims
`test/parity/parity_helpers.jl`'s `_parity_prepend_twin_lib!()` used to read
`GLLVM_PARITY_R_LIBS` itself and silently fall back to R's default library
when the named path had no gllvmTMB. This PR routes it (and 7 tools that
called `library(gllvmTMB)` directly) through the existing `second_order_r_lib()`
guard (added in PR #474), which throws instead of falling back, and adds a
`test/test_second_order_r_libs.jl` regression test plus a provenance audit
doc.

## Checks performed

  `_parity_prepend_twin_lib!()` calls `something(second_order_r_lib(),

  `loaded_from() != expected` after `library(gllvmTMB, lib.loc = twin)`,
